# Dataset

This project uses the **New York State SPARCS Hospital Inpatient Discharges (De-Identified)** dataset from the New York State Open Data platform.

The dataset contains de-identified information on hospital inpatient discharges, including diagnoses, procedures, length of stay, admission type, severity of illness, patient disposition, and financial measures.

The original dataset is not included in this repository because of its size and data-distribution considerations.

## Dataset Details

- **Records:** 2.1M+ inpatient discharges
- **Geographic scope:** New York State
- **Data type:** De-identified hospital inpatient discharge data
- **Primary financial measure used:** Total Costs
- **Key utilization measure:** Length of Stay

The data was processed in Python before being used for the Power BI analysis.

## Source

New York State Open Data — SPARCS Hospital Inpatient Discharges (De-Identified)

The original dataset can be obtained from the official New York State Open Data platform.
