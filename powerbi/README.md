# Power BI Dashboard

This folder contains documentation and exported materials related to the Power BI dashboard.

The final dashboard consists of three pages:

1. Hospital Inpatient Cost & Utilization Analysis
2. Hospital Resource Utilization & Cost Efficiency
3. Hospital Utilization & Patient Analysis

The editable `.pbix` file is not included in this repository because of its file size.

Screenshots of the final dashboard pages are available in the `images/` folder.
